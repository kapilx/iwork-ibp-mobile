# Enrollment Sample Excel

This folder contains a minimal Excel file (`enrollment_sample.xlsx`) that can be uploaded via the policy enrollment upload API. The file includes one example employee record and uses the following columns:

- Policy ID
- Employee Company ID
- Employee Name
- Full Name
- Date of Birth
- Gender
- Email
- Phone Number
- Designation
- Relation Group
- Marital Status

Use this file to test the enrollment upload and scheduler processing pipeline.
