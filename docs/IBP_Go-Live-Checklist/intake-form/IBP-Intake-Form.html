Welcome

Integrated Wellness Hub (IWH) — Portal Setup

Welcome to the Integrated Wellness Hub (IWH) (Internally it is called as IBP - Integrated Benefits Portal) setup form.

This form collects everything IIRM team needs to configure your company group insurance policies (Refer below for policy types) on the portal. The sections follow the same order your employees will experience the portal — from the login screen, through first login and the dashboard, to enrollment — so you can picture each answer on the screen it shapes.

  1. Group Mediclaim
  2. Group Mediclaim Top-up
  3. Group Personal Accidental
  4. Group Personal Accidental Top-up
  5. Group Term Life
  6. Group Term Life Top-up
  7. Parental
  8. Parental Top-up
  9. Any other health related

Who fills this: your CRM contact at IIRM, or your HR team — sections are labelled with an owner badge so you always know whose input is needed. Fields marked IIRM to fill are completed by IIRM and are shown only for transparency.

Time needed: roughly 30–45 minutes if the pre-requisites below are ready. Your entries stay in this page until you export — nothing is submitted automatically.

Section 2Stage 1

Login Screen — Branding & Sign-in

Not started

The first screen every user sees at your portal address (for example https://democorporation.iwh.indiainsure.com/). These inputs decide what that screen shows and how employees sign in from it.

Branding

B1 Company logo*Ideally 200×200 px

Your company logo image file. It appears on the portal login page and in the header your employees see every day.

PNG; JPG; SVG; max 2 MB

IIRM: iWork → Company Details → Edit Company → logo upload.

B2 Login welcome message — heading

A short greeting line employees see on the login page. Leave blank to use the standard greeting.

IIRM: Portal Configuration — welcome heading.

B3 Login welcome message — body text

One or two friendly sentences under the greeting, telling employees what they can do on the portal.

IIRM: Portal Configuration — welcome body text.

Login Options

Choose how employees sign in. You can enable more than one method; each enabled method has its own settings in the groups below.

L1 How should employees log in?*Tick every method to enable

The sign-in methods your employees can use on the portal.

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — method cards.

L7 Login data requirement

Make sure your employee data has these columns filled before go-live.

IMPORTANT: If a chosen method uses Email (Email + Password, Email + OTP), the Email column is mandatory for every employee in the inception / endorsement data. If it uses Phone (Phone Number + Password, Mobile + OTP), the Mobile number column is mandatory. Employees missing that data cannot log in.

IIRM: Login identifiers come from inception / endorsement records.

Password Settings

Answer only if a chosen method includes a password (Email + Password, Phone Number + Password).

L4 Password — minimum length

The smallest number of characters a password must have. 8 is the default.

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — Password Policy.

L6 Password — must includeTick all that apply

What every password must contain — capital letter, small letter, number, special character.

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — Password Policy must-include toggles.

L8 Password expiry

How often employees must set a new password. 90 days is the default.

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — Password Expiry.

L9 Require old password to change password?

When changing their password, must employees first enter their current one?

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — Change Password Policy.

L2 Enable 2 Factor Authentication?

An extra security step: after the password, employees also enter a one-time code (OTP).

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — 2 Factor Authentication toggle.

OTP Settings

Answer if a chosen method includes OTP (Email + OTP, Mobile + OTP), or if you enabled 2 Factor Authentication above.

L3 2FA OTP deliveryOnly if 2FA is Yes — select one or more

Where the one-time code goes after a successful password login.

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — 2FA OTP Delivery Method.

L10 OTP validity duration (minutes)

How long a one-time code stays valid before it expires. 5 minutes is the default.

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — OTP Configuration.

L11 Resend OTP cooldown

How long an employee must wait before asking for a new code.

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — OTP Configuration.

Employee ID Settings

Answer only if you chose Employee ID + Year of Birth. Note — this method sends no welcome message and no reminders, since there is no email or phone to send them to.

L12 Validate employee ID format at login?

Should the portal check that the typed employee ID matches your company's ID pattern?

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — Employee ID Format Validation toggle.

L13 Employee ID format mask

Your employee ID pattern. Use X for any character and 9 for a digit — for example EMP-99999 for "EMP-" followed by five digits.

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — format mask field.

Session

L14 Session timeout*

How long the portal stays signed in with no activity before logging the employee out. 30 minutes is the default.

IIRM: iWork Edge → My Company → Configure IBP Portal → Login & Authentication — Session Timeout (applies to every method).
