Schedule Callback 

Employee portal

*  This is the feature where user can schedule a call back.  
* User clicks on the “ Schedule callback” CTA on the dashboard screen  
* User lands on the screen where the user can select.  
* Category  (Mandatory)  
  *  Policy / Benefits related  
  * Claims Assistance  
  * Enrolment Support  
  * E-Card Support  
  * Wellness support  
  * Others  
* Description (Optional)  
* Time Window ( should be Future )   
* Name (Mandatory)  
* Phone Number (Mandatory)  
* Submit / Cancel  
* Confirmation Notification
